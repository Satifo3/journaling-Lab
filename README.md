# Journal Lab v0.5 Single File

- GitHubへアップロードするのは `index.html` 1個だけ
- デイリータスク入力 + 4つの習慣チェックを同じ行に横並び
- 4枠は1px間隔で、4つ埋めると黒い帯に近く見えるコンパクト配置
- BGMは4種類ともこのHTML内に実音声WAVを埋め込み済み
- 春日部つむぎWAVはFocus画面からiPhoneのファイル選択で読み込み可能
- 読み込んだWAVはIndexedDBに端末内保存し、GitHubへアップロード不要
- WAV未登録時はiPhoneの日本語読み上げで代替

VOICEVOXの春日部つむぎ音声を使う場合のクレジット:
VOICEVOX:春日部つむぎ
